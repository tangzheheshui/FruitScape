**方向 1｜Vibe Coding 开发记录（立人设、拉精准人群）**

### 2.3 笔记示例（可直接用）——以 5 月为例

**标题**（任选其一）：
- 《5 月露天应季水果｜只有这几种是树上刚摘的》
- 《5 月别乱买水果！露天自然熟的只有这 6 种》

**正文**：
> 5 月了，市面上水果开始多起来，但真正「露天自然熟」的其实没几种。
>
> 🍒 樱桃（山东烟台）——5 月底才熟，早于这个点的多是温室果
> 🍈 荔枝·白糖罂（广东茂名）——露天自然果，4 月那种大多是大棚早熟
> 🥭 贵妃芒（海南三亚）——皮黄≠熟透，注意套袋催熟
> 🍓 露天草莓（云南红河）——北方草莓基本都是大棚货
> 🍑 白玉枇杷（江苏苏州）——5 月中自然熟，早市多是大棚
>
> 完整清单 + 产地地图，小程序搜「时令果册」直接看。
> 收藏起来，照着买不踩坑。

## 三、公众号（长文沉淀 + SEO 长尾）

### 3.1 定位分工
- 小红书：短、快、种草、直接引流
- 公众号：长文、深度科普、可搜索、沉淀信任（微信内搜索「时令水果」「露天水果」等关键词的长尾流量）

### 3.2 文章方向与大纲

**①《为什么你买的「当季水果」其实是冷库货？》——科普长文（引流主文）**
- 开头：一个反常识钩子——「你 4 月买的荔枝，去年 6 月就摘了」
- 主体：
  1. 三种「非当季」来源：大棚早熟 / 冷库储藏 / 南半球进口
  2. 为什么它们口感差、风味弱（糖酸积累、香气物质流失）
  3. 一张「全年露天果时间轴」（可直接引用小程序数据）
  4. 怎么辨别：看产地、看上市时间、看价格拐点
- 结尾：引导关注 + 体验小程序

**②《5 月露天应季水果清单（附产地地图）》——月度栏目（全年可复制）**
- 结构：当月清单表格 + 每种的「避坑提示」+ 产地地图截图 + 小程序引导
- 可做成固定模板，每月更新一篇

**③《我用 AI 写了一个水果地图小程序｜Vibe Coding 复盘》——开发复盘（双人群）**
- 大纲：
  1. 起因：想解决「买不到真正当季水果」的问题
  2. 过程：PRD → 让 AI 生成原生小程序 → 静态 JSON → 本地存储，无后端
  3. 踩坑：map 组件游客模式、定位权限弹窗、Canvas 2D 海报
  4. 结果与下一步：云开发、用户纠错、订阅提醒
  5. 附：完整目录结构 + 关键代码片段

## 五、内容生产建议
1. **海报即素材**：小程序 Canvas 生成的海报自带品牌名 + slogan，直接作为笔记配图，内容与产品互相导流。
2. **数据即内容**：`data/fruit_data.js` 里 52 条果实的「避坑提示」就是现成的科普素材，按月切片即可成文。
3. **固定栏目**：月度清单做成模板后，每月只需更新月份和当季果实，边际成本极低。
