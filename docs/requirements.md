# 时令果册 · 最终需求总结

> 一句话定位：**看露天应季水果，拒绝大棚反季。**

| 项 | 内容 |
|---|---|
| 产品名 | 时令果册（GitHub 仓库：FruitScape） |
| Slogan | 看露天应季水果，拒绝大棚反季 |
| 形态 | 微信小程序（原生） |
| AppID | `wx0feb0343112255c2`（个人主体） |
| 数据规模 | 52 种果实 · 19 个省份 · 28 个品类 · 12 个月全覆盖 |

---

## 1. 产品定位与核心价值

一个**只展示「露天自然成熟」水果**的应季地图小程序，帮用户搞清楚「现在这个季节，哪里有哪些水果是露天自然熟的」。

**差异化核心 = 避坑提示**：每条数据都带一条「避坑提示」，标注市面上同款水果哪些多为大棚早熟、冷库囤货、南半球进口反季——这正是「拒绝大棚反季」的落点。

## 2. 目标用户

- 关注时令、想吃到自然成熟水果的消费者。
- 对「大棚反季 / 冷库囤货 / 进口反季」有排斥、追求应季本味的人。
- 小红书 / 公众号读者——被「避坑」内容种草后进小程序查证。

## 3. 数据准入原则

**只收录**：露天自然成熟、应季上市的水果。

**排除**：
- 大棚早熟 / 反季种植
- 冷库储存（陈年货）
- 南半球进口反季水果

每条数据**必须**携带「避坑提示（tip）」。

## 4. 功能范围

## 5. 数据模型

每条果实字段：

```
id / name / category / province / city / lat / lng
/ startMonth / endMonth / variety / tip
```

- `startMonth > endMonth` 表示**跨年上市**（如沙糖橘 12 月–次年 1 月），代码已处理。
- 当前：52 种 · 19 省份 · 28 品类 · 12 个月全覆盖。

## 6. 技术方案

- 微信小程序**原生**（wxml / wxss / js），无组件库、无后端。
- 数据：`data/fruit_data.js` 静态本地数据（`module.exports`）。
- 收藏：`wx.setStorageSync` 本地存储。
- 地图：原生 `<map>`；点位图标 + label（label 点击已兼容处理）。
- 海报：Canvas 2D。
- 隐私授权：`utils/privacy.js` 兜底（写入相册）。
- 反馈：客服消息（`open-type="contact"`）。

## 7. 内容运营

- **小红书**：避坑清单、月度应季海报、产区故事。
- **公众号**：同主题深度内容。
- 详见 `docs/content-plan.md`。

## 8. 发布与合规

- 需配置「用户隐私保护指引」：勾选**相册（仅写入）**。
- V1 无后端，暂不需要域名 / ICP 备案 / HTTPS；**引入自建后端后**才需要 ICP 备案 + HTTPS + 合法域名白名单。
- 详见 `docs/publish-guide.md`。
