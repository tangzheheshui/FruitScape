# 时令果册 · 小程序发布指南

> 从「代码写完了」到「正式上线」，完整流程 + 本项目可直接复制的填写文案。

---

## 0. 总览流程

```
注册账号 → 拿到 AppID → 填基本信息(名称/头像/类目) → 配置隐私指引
        → ICP 备案 → 开发者工具上传代码 → 后台提交审核 → 审核通过 → 发布
```

---

## 1. 前置决策：选什么主体？（先定这个，再往下走）

| 维度 | 个人主体 | 企业 / 个体工商户 |
|------|---------|------------------|
| 注册门槛 | 免费、身份证即可 | 需要营业执照（个体户也能办） |
| 备案 | 可备 | 可备 |
| **`wx.getLocation` 定位** | ❌ 基本申请不到 | ✅ 可申请（需匹配类目） |
| 微信支付等能力 | ❌ 大多不可用 | ✅ 可用 |

> 关键结论：**「附近」页依赖定位，个人主体大概率用不了定位功能。**
> 本项目已做降级处理：定位失败时，可在「附近」页切换到「按省份查」，个人主体也能完整使用。

## 2. 分步操作

### 第 1 步：注册账号，拿 AppID
1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 选择「小程序」
2. 选择主体类型，填邮箱激活，按提示完成注册
3. 登录后台 →「设置 → 基本设置 → 账号信息」→ 复制 **AppID**

### 第 2 步：把 AppID 填进项目
- 编辑 `project.config.json`，把 `"appid"` 改成你的 AppID
- 用微信开发者工具重新导入项目（否则 `<map>` 地图不渲染）

### 第 3 步：填写基本信息
后台「设置 → 基本设置」，参考以下文案：

| 项 | 填写内容 |
|----|----------|
| 名称 | 时令果册（若被占用，可加后缀：时令果册Pro / 时令果册·应季 / 露天果册） |
| 头像 | 上传 `images/app-icon.png` |
| 简介 | 展示露天自然成熟应季水果的产地与上市时间，帮你避开大棚早熟、冷库储藏和进口反季果 |
| 服务类目 | 建议选「工具 → 信息查询」，如无此细类则选最贴近的「生活服务」类（**类目必须与实际功能一致，否则打回**） |

### 第 4 步：配置「用户隐私保护指引」
后台「设置 → 服务内容声明 → 用户隐私保护指引」：
- 勾选涉及的信息类型：**位置信息**
- 用途说明（直接复制）：
  > 位置仅用于在用户设备本地计算「用户到各水果产区的直线距离」，不收集、不存储、不上传任何位置数据。

> 不配置此项，真机上调用定位会被系统拦截。

### 第 5 步：ICP 备案
后台「设置 → 基本设置 → 小程序备案」，按提示提交（需身份证/营业执照、手机号）。审核周期通常几天，**未备案无法发布**。

### 第 6 步：开发者工具上传代码
1. 工具里开发、真机预览确认无误
2. 点右上角「**上传**」，填版本号（如 `1.0.0`）和备注（如「MVP 首版：月份/地图/搜索/附近/收藏/海报」）

### 第 7 步：后台提交审核
1. 后台「管理 → 版本管理」→ 找到「开发版本」→「提交审核」
2. 填写审核信息：
   - 页面功能说明（参考下方「审核文案」）
   - 若审核需要测试账号/说明，如实填写「无需登录，无需测试账号」

### 第 8 步：审核通过 → 发布
- 审核一般 1~3 个工作日
- 通过后回到「版本管理」点「**发布**」
- 审核期间可先点「**选为体验版**」生成二维码，分享给朋友真机测试

## 3. 审核文案（可直接复制）

**页面功能说明：**
> 首页：按月切换，在地图上展示当月露天应季水果的产地分布，点击查看产地、赏味期、品种与选购提示。
> 搜索页：支持按水果名称、按省份检索露天应季水果。
> 附近页：经用户授权定位后，按距离排序展示离用户最近的当季产区（仅本地计算，不上传）；无定位权限时可切换为按省份查询。
> 收藏页：收藏关注的水果/产区，数据保存在用户本地。
> 海报页：生成本月露天应季水果清单图片，可保存到相册。
> 关于页：产品说明与免责声明。
>
> 本小程序不售卖商品、不推荐商家、不提供价格行情、不接入任何电商跳转，仅提供时令水果信息参考。

## 4. 常见驳回原因 & 对策

| 驳回原因 | 对策 |
|----------|------|
| 类目与实际功能不符 | 选择「工具-信息查询」而非「食品/电商」类 |
| 涉及销售/导购嫌疑 | 强调「不售卖、不导购、无交易」，避免文案出现「购买」「价格」 |
| 隐私指引缺失 | 按第 4 步补配置 |
| 定位权限滥用 | 说明「仅本地计算、不上传」，且定位由用户主动点击触发（本项目已实现） |
| 名称与简介不符 | 名称、简介、页面功能三者保持一致，都围绕「时令水果信息查询」 |

## 5. 本项目「附近」页的定位降级说明
- 企业/个体户主体：正常使用「获取我的位置」自动定位排序
- 个人主体：定位会被系统拒绝，页面会提示，并可在顶部切换到「按省份查」，功能不受影响
- 两者共用同一份 `data/fruit_data.js`，无需后端
